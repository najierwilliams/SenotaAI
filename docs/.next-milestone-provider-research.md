# Next Milestone Provider Research

## Julich v3.1 / siibra evidence

Official siibra documentation demonstrates Julich v3.1 region hierarchy and provider-native identifiers, including an amygdala parent and cytoarchitectonic children such as CM, LB, SF, MF, IF, VTM, and Astr. The same documentation demonstrates that region lookup is provider-parcellation scoped and that a query can return a parent when a specification spans child regions. It does not publish a UBERON/FMA-to-Julich crosswalk for use as an automatic Luna mapping. Source: https://siibra-python.readthedocs.io/en/v1/examples/01_atlases_and_parcellations/003_find_regions.html

The EBRAINS v3.1 dataset record identifies 207 default-granularity maps and 227 high-granularity maps, with probability maps, gap maps, and MPMs in MNI ICBM 152 2009c nonlinear asymmetric, Colin27, and fsaverage. It identifies CC BY-NC-SA 4.0 and does not grant automatic redistribution beyond the declared terms. Source: https://search.kg.ebrains.eu/instances/f1fe19e8-99bd-44bc-9616-a52850680777

Forschungszentrum Jülich confirms v3.1 is a probabilistic 3D atlas that includes cortical and subcortical structures and supports MNI152, Colin27, and fsaverage products. Source: https://www.fz-juelich.de/en/news/archive/new-release-of-the-julich-brain-atlas-adds-52-new-maps

## Scope consequence

Provider-specific Julich region records may be represented as provider-scoped, one-to-many cytoarchitectonic context only after an explicit provider-region relation is obtained. The examples show why a broad canonical entity such as amygdala cannot be silently upgraded to a single deterministic cytoarchitectonic subregion. No provider documentation retrieved establishes an authoritative UBERON/HRA-to-Julich mapping for Luna, so Luna structure observations remain `structure-context`.

## BigBrain and multiscale context

The July 2026 Jülich description confirms siibra links macroscopic MNI reference spaces, BigBrain, and Julich as an anatomical reference, supporting metadata-first region-specific access to large data. It does not establish a Luna relation. BigBrain remains provider-scoped context with no raw download or transform composition into Luna. Source: https://julich-brain-atlas.de/news/2026-07-molecules-networks-siibra-integrates-brain-data-unified-atlas
